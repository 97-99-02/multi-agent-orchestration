# Agent 과제 역할 분담 (Supervisor 패턴)

RAG 과제(`97-99-02/ai-startup-investment-agent`)의 투자 평가 에이전트를 Supervisor 패턴으로 바꾸는 작업의 담당 영역이다.
RAG 과제에서 각자 만든 에이전트를 그대로 맡고, 새로 생기는 조정 계층(Supervisor, State, Graph)은 한 사람이 맡는다.

- 저장소: `97-99-02/multi-agent-orchestration`, 통합 브랜치 `agent/supervisor`

## 담당 영역

| 담당 | 영역 | 관련 파일 |
|---|---|---|
| 이채목 | State 재설계(제어 필드와 결과 데이터 분리, reducer), Supervisor(근거 충분성 판정, 라우팅 규칙, 결정 로그), Star 구조 그래프, trace_id·체크포인터·실행 설정, 탐색(`current_index`를 Supervisor로 이관), 팀 분석·경쟁사 비교 재작업, 전체 실행과 LangSmith 트레이스 | `state.py`, `agents/supervisor.py`, `graph.py`, `app.py`, `obs.py`, `config.py`, `agents/explorer.py`, `agents/team.py`, `agents/competitor.py` |
| 장정훈 | 기술 요약 재작업(재작업 요청의 빈 항목으로 검색어를 바꿔 재검색, 이미 확인한 사실 유지), `diagnostics`를 State 밖 로그로 분리 | `agents/tech_summary.py` |
| 강지수 | 시장성 재작업(상위 분야까지 검색 확장), 과제 해석 확인(4관점·중립성), README(Pattern 선정 이유, 동적 처리, Evaluation Target, State Schema 7항목) | `agents/market.py`, `README.md` |
| 김다은 | 보고서 품질 평가 노드(코드 검사 + LLM Judge: Groundedness, 중립성, 편향 통제, 관점 커버리지), 투자 판단 노드 예외 처리 | `agents/quality.py`, `agents/judge.py` |
| 이진우 | 보고서가 품질 평가 수정 지시를 받도록 변경, 재작성 한도 관리를 Supervisor로 이관, 4관점 목차·10장 이내·파일명, 사실 검증과 품질 평가 연결, PDF | `agents/reporter.py`, `agents/verifier.py` |

## 먼저 맞춰 둘 형식

각자 영역이 이어지는 지점이다. 바꿀 때는 이 문서를 먼저 고친다.

```python
# 재작업 요청 (Supervisor가 쓰고, 각 에이전트가 읽음)
rework_request = {"tech_summary": {"reason": "개발 단계·성능 수치 없음",
                                   "focus": ["development_stage", "performance_metrics"]}}

# 근거 충분성 판정 (Supervisor가 씀)
evidence_status = {"market": {"sufficient": False, "reason": "세부 분야 성장률 없음"}}

# 품질 평가 결과 (quality가 쓰고, Supervisor·reporter가 읽음)
eval_result = {"passed": False, "report_version": 2,
               "items": {"groundedness": {"passed": True, "reasons": []}},
               "fix_instructions": "..."}

# 보고서 버전 (재작성할 때마다 +1, verify_result·eval_result에도 같은 값을 기록)
report_version = 1
```

- 하위 에이전트는 자기 결과 키, `sources`, `agent_errors`만 반환한다.
- 제어 키(`current_index`, `retry_count`, `rework_request`, `rework_count`, `evidence_status`, `report_version`, `step_count` 등)는 Supervisor만 쓴다.
